How It Works

This tool uses a Multiple Linear Regression model trained on 712 cleaned records from Quikr's used-car listings.


Pipeline steps:
1. Drop "Ask For Price" rows
2. Remove junk / scraped year values
3. Cast Price, kms_driven to numeric
4. Remove junk company entries
5. Drop remaining nulls
6. Remove duplicate rows
7. Outlier filtering
8. Feature engineering (car_age)
9. One-hot encode categoricals
10. Train / test split (80/20)
11. Train LinearRegression (scaled)
