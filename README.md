#  Car Price Predictor

A full-stack machine learning web application that predicts used car prices
based on real Quikr listings data.

## Tech Stack

| Layer | Technology |
|---|---|
| ML Model | Multiple Linear Regression (scikit-learn) |
| Backend | FastAPI + Uvicorn |
| Database | SQLite |
| Frontend | HTML + CSS + JavaScript |

## Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/YourUsername/car-price-predictor.git
cd car-price-predictor
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Train the model
```bash
python backend/train.py
```

### 4. Start the server
```bash
python -m uvicorn backend.app:app --reload --port 8000
```

### 5. Open in browser
http://localhost:8000


## ML Pipeline

1. Drop rows with no price ("Ask For Price")
2. Remove junk year values using regex
3. Clean and cast Price, kms_driven to numeric
4. Remove invalid company entries
5. Drop rows with missing values
6. Remove duplicate rows
7. Outlier filtering (Price, kms_driven)
8. Feature engineering (car_age, name truncation)
9. One-hot encode categoricals (280 features)
10. Train/test split (80/20)
11. StandardScaler for feature scaling
12. Train Multiple Linear Regression

## Model Performance

| R² Score | 0.729 |
| MAE | ₹1,01,447 |

**Note:** Multiple Linear Regression achieves R² = 0.729 on this dataset.
The strong performance is attributed to one-hot encoding of car name and
company, which allows the model to learn average price patterns per car model
effectively. MAE of ₹1,01,447 means predictions are on average off by
approximately ₹1 lakh.
